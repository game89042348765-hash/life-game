# LifeGame — простой чек-лист

Перед проверкой сохрани JSON-копию своего прогресса; эксперименты с покупками и восстановлением делай в отдельном профиле браузера. Сбрасывать свои данные не требуется.

- [ ] Прежние монеты, алмазы, блоки, задания, цели, квесты и коллекция на месте.
- [ ] На главной открываются все прежние разделы, включая маршрут, ништяки, итоги и LifeGame AI.
- [ ] Добавление виджета оставляет каталог открытым; «Перейти к виджету» показывает нужную карточку с подсветкой.
- [ ] Возврат в длинный список сохраняет место. Стрелки порядка и размещение в Конструкторе работают.
- [ ] Созданное задание сразу видно; дни повторения, награда и связь с целью соответствуют форме. Создание ничего не выполняет автоматически.
- [ ] На узком экране поля доступны прокруткой, кнопки формы видны. Пустое обязательное поле не принимается; Escape/Назад защищает изменённую форму.
- [ ] «Управление списком» содержит прежние сортировку и массовый выбор для удаления. Проверять удаление своих данных не нужно.
- [ ] В тестовом профиле три задания по 15 дают 45 монет + 100 бонуса дня; цель даёт заданные алмазы. Виджеты не считаются заданиями.
- [ ] Этапы квеста и допустимая отмена работают. Календарь помнит месяц после перехода; «Сегодня» возвращает текущую дату. Покупки учитывают выбранную валюту.
- [ ] Таймер работает после паузы и перезагрузки. Минуты ключевых действий записываются отдельно, таймер их не начисляет.
- [ ] В счастье доступны игра и прямая «Коллекция», добавление и редактирование момента. Удаление виджета из сборки сохраняет его данные.
- [ ] Браузерный «Назад» сначала закрывает окно, затем возвращает к экрану. В маршруте возвращает к шагу и защищает выход с черновиком.
- [ ] Настройки → «Скачать JSON-копию» скачивает файл. Выбор файла показывает дату и количества; восстановление требует подтверждения полной замены. Последнее проверяй только в тестовом профиле.
- [ ] На своём телефоне проверь нижнюю панель, клавиатуру, длинное название, чат и таймер после блокировки экрана.

Реальные Safari/iOS/Android и платные API ещё не проверены. Ключ ИИ вводи только в приложении; реальный запрос может быть платным. Парные снимки: review/index.html. Замечание можно вернуть в виде «пункт — устройство — что произошло».
