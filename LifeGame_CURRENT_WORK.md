## Что теперь видно

- У блока два вида: **Действовать / Путь**. Бытовой вариант — **Действовать / План**. По умолчанию открывается рабочий вид. Повтор верхних ссылок на остальные разделы убран из деталей блока; настройки открываются отдельным меню.
- Текущий этап стал спокойнее: необязательный смысл, результат/цель, дела и отдельное свёрнутое «Сделано». Завершённые строки не содержат переключателей Конструктора/избранного. Все второстепенные команды доступны через ⋯.
- Быстрое добавление прямо в этапе: одно название и +, разовое дело за 25 монет, без автоматического Конструктора. Создание не выдаёт награду. «С параметрами» открывает принятую форму со звездой, подхватив название. У бытового блока форма проще и без светового ползунка.
- Настройки блока, меню задания, смысл/цель, переход и редактор этапа приведены к одной графитовой поверхности. Доступ к этапу — дополнительная секция редактора. Необязательные возможности перестали занимать основной экран, данные/ID не удалены.
- Завершение этапа показывает следующий шаг и объясняет историю. Прошлые дела остаются в своём этапе и невыполненном, новые начисления за переход не придуманы.
- Переключатель **Большой путь** в создании/настройках. Включён: звёзды, ориентир, неизвестность, свет. Выключен: бытовой блок, спокойный графит, короткий план «Сейчас → Дальше → Готово». В JSON добавлено kind (journey/everyday), старые блоки по умолчанию journey. Переключение сохраняет этапы, задания, цели и ledger. На бытовом финише перехода в неизвестность нет.
- После успешного начисления монет в блоках нет баннера: в пути сначала завершается анимация, затем верхний счётчик пересчитывает итог с мягким звуком. Реальный баланс записан сразу; ноль только визуальный. В рабочем/бытовом виде пересчёт без полёта. При выключенном звуке тихо; reduced motion без сброса цифр в ноль. При уходе эффекты очищаются.
