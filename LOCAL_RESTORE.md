# Полная локальная копия LifeGame

Архив проекта содержит index.html, локальные изображения/скрипты, все демо, правила работы, текущий статус, паспорт, передачу контекста, UX-отчёты и папку backups с копиями кода. Ссылка ZIP привязана к конкретному коммиту: последующие обновления сайта не меняют скачанную версию.

## Запуск

1. Распакуй ZIP в отдельную папку. Открой эту папку в VS Code.
2. В терминале этой папки запусти `python -m http.server 8080` (в Linux/macOS команда может называться `python3`).
3. Открой http://localhost:8080/ . Такой запуск позволяет автоматически читать локальную базу Игры в счастье и остальные ресурсы.

index.html также можно открыть напрямую, но браузер может ограничить загрузку локального JSON; HTTP удобнее для полной проверки.

## Продолжение с агентом

Сначала прочитать AGENTS.md, LifeGame_CURRENT_WORK.md, LifeGame_PROJECT_CONTEXT.md и LifeGame_CHAT_HANDOFF_2026-11-06.md. Сверить состояние файлов с описанием; точка продолжения указана в передаче контекста. Выполнен этап 1 — быстрое добавление и Входящие. Следующий этап — разбор вчерашних незавершённых дел.

GitHub: https://github.com/game89042348765-hash/life-game . Сайт: https://game89042348765-hash.github.io/life-game/ . ZIP не содержит служебную папку .git и историю коммитов; исходники и документы доступны автономно. При необходимости Git-истории используй обычный clone репозитория.

## Что сохраняется отдельно

Прогресс приложения находится в браузере и не входит в исходники. Для переноса прогресса используется Настройки → Скачать JSON-копию; восстановление заменяет прогресс целиком. Не помещай личный JSON и API-ключи в публичный репозиторий. backups содержит версии HTML, а не личный прогресс.

Ключи и сеансы AI не включаются в архив. Облачные инструменты и подключённые сервисы на локальный компьютер автоматически не переносятся.
