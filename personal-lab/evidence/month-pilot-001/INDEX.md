# Переносимые доказательства пилота LAB-002

Срез: 3 AI-пользователя, 7 виртуальных дат, 16 открытых сессий, 5 дней без входа, 120 действий. Все данные вымышленные. Это компактный набор для Git, а не полный архив облачной машины.

Начните с [переносимого анализа](REVIEW.md), [сводки](facts-report.json), [журнала событий](events.jsonl) и [каталога с SHA-256](MANIFEST.json). В REVIEW изменены только ссылки; исходный независимый ANALYSIS.md оставлен без изменений.

Включены все JSON-наблюдения и 16 снимков состояния пользователей, исходные условия/версия движка, ключевые PNG, два полных успешных UI-воспроизведения аналитика со своими trace.zip и отдельные технические проверки исправленного наблюдения. Первичный ошибочный отчёт Node-анализатора тоже сохранён и помечен по имени.

Проверка после получения ветки, из корня checkout:

```sh
python3 personal-lab/evidence/verify.py
```

Проверка не требует запуска приложения, браузера, модели или сетевых запросов. Она сверяет каждый включённый исходный файл с MANIFEST и реальные счётчики пилота. Для открытия trace используйте установленный Playwright Trace Viewer; сам ZIP также доступен для локальной проверки.

Внутри исходных JSON остаются пути машины исполнения (`verification/...`). Для чтения в другом checkout используйте одноимённые файлы относительно этого каталога. Исходные JSON не переписывались, поэтому их хеши сохраняются.

## Omitted artifacts

Полные 16 трасс пользовательского пилота и невыбранные PNG остались локально в `personal-lab/verification/month-pilot-001/`; их размер и SHA-256 перечислены в MANIFEST с `included: false`. Ссылки на отсутствующие файлы в REVIEW явно ведут сюда. Не считать их загруженными на GitHub.

Браузерные профили, cookies/cache, дубликат приложения и первый неудачный прогон аналитического скрипта не включены. Последний описан в анализе; успешное повторное воспроизведение сохранено полностью. История действий всех трёх пользователей и все 16 конечных состояний сессий включены, поэтому основные выводы можно проверить без профилей.

Для воспроизведения используйте версионированный `research/LAB-002-digital-month/reproduce.py` и исходники лаборатории. Это создаст новый опыт, а не восстановит каждое решение исходной модели. Синтетические агенты не дают статистики человеческого удержания.
