# LAB-016 — описание выполненной работы

**Дата:** 13 ноября 2026, Europe/Moscow. **Запрос:** выдать обычный скачиваемый архив важных файлов для работы другой модели, без бекапов/лишнего, желательно до 100 МБ. **Исходник:** 89112c29dacea254cd8f50c4197a8ee77e764917, lab/synthetic-users. До сборки сверены удалённые ветки; main остаётся 90df954. Модель-разработчик может работать по приложенным файлам без доступа к репозиторию.

Из 1229 файлов выбранного Git-среза взяты 570: весь текущий код/ресурсы шести приложений, их тесты/правила/документы, полезные демо/основания решений, текущие LAB-013/015 и инструменты стенда, самостоятельная рабочая release «ГИДРЫ». Не включены backups/history/rebuild-снимки, все прежние ZIP, тяжёлые traces, старый объёмный пилот, отклонённые конвейеры и устаревшие задания. Выбор и причина каждого исключения записаны в OMITTED. Это срез текущей рабочей ветки, а не backup всех Git refs.

Новый build_pack.py читает закреплённые Git blobs через batch и не переписывает исходники. Сохраняет исходные пути, SHA и режимы файлов, добавляет три коротких вводных для внешней модели, таблицу разделов, SOURCE/MANIFEST/OMITTED и независимый verify_package.py. Архиватор/операционная система не требуют Git для распаковки. Проверка исходного комплекта работает на стандартном Python. Приложения запускаются обычным локальным HTTP-сервером.

Вводные отделяют основную Personal от лаборатории/Базового/AI/Next/root, указывают актуальные документы и ограничения сохранений/наград. Пользовательское задание остаётся определяющим; пакет сам по себе не поручает редизайн. Модель получает готовый шаблон задания и формат возврата только изменённых файлов с исходными SHA/описанием/реальными проверками. Правила экономии/распределения ролей лаборатории не перенесены на процесс главной модели основной Personal. Концепции, планы и примеры не выданы за реализованные функции или реальные результаты.

Отдельно раскрыты ограничения: Git-истории нет, поэтому historical git-show тест daily-ux.py и старый сборщик LAB-014 не воспроизводятся одним наличием файлов; требуются исходные объекты. Старые Markdown могут ссылаться на намеренно исключённые архивы/историю. Не заявлена возможность открыть недоступные полные traces или запустить платные API. Реальный пользовательский прогресс/ключи/браузерные профили не включались; данные компактных свидетельств LAB-015 вымышленные и уже опубликованы в репозитории.

Окончательный ZIP: 15 835 996 байт, 578 записей, 577 хешей манифеста, 24 871 729 байт после распаковки. Все 570 файлов репозитория побайтово равны базе. CRC/размеры/SHA и отсутствие backup/history/nested ZIP/.bundle проверены. В чистой распаковке без Git прошёл verify_package.py; синтаксис включённых Python проверен. В изолированных Chromium-контекстах открылись шесть приложений с настоящего локального сервера: интерактивные экраны, JS без ошибок, все запрошенные локальные ресурсы доступны, внешних запросов нет. Это проверка комплектации/первого открытия, а не повторная приёмка всех функций. После cold-open уточнены только вводная о Git-зависимых проверках и счётчик CONTENTS; все 570 исходных файлов конечного пакета совпадают с проверенным вариантом.
