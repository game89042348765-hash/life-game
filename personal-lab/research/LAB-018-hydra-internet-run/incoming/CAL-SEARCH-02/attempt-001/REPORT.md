## Доступ и фактическая работа

Специализированного инструмента веб-поиска не было. Использованы обычный Python urllib.request с наследуемым HTTP-прокси, lxml для серверного HTML и pdftotext для скачанного PDF. Навык cloud-environment-runtime и его networking reference прочитаны; свежий environment_status сообщил `unrestricted`, `enforced`, `observations_current=true`. Локальный startup snapshot по сети был более старым restricted-снимком и не принимался за текущую политику. Среда и настройки сети не менялись.

Журнал содержит 33 фактических запроса с URL, временем, HTTP-статусом, результатом и ограничениями: 29 HTTP 200, 3 HTTP 404, 1 тайм-аут. Восемь публичных запросов: четыре Bing и четыре Brave. Bing отдавал в основном однословные/омонимичные результаты, не соответствующие полному запросу; это ограничение зафиксировано, такие результаты не служат доказательством. Brave вернул полезные органические ссылки, по которым отдельно открыты PDF Spoon Theory и консультация ГАРАНТ. Остальные материалы открывались по известным адресам и по реально просмотренной навигации; происхождение переходов сохранено в action журнала. Поисковые фрагменты не использованы как подтверждение существования.

HTML-перенаправления Anki FAQ и Workrave прочитаны только как навигация; из них не извлекались verified-находки. Содержательный main Anki доступен в HTTP-ответе и действительно прочитан. Оригинальная страница Spoon Theory завершилась тайм-аутом; фактически прочитана разрешённая атрибутированная перепечатка, что отдельно указано. JS-оболочки и CAPTCHA не засчитывались прочитанными материалами и не обходились.

Трансфер из игры и шахмат в организацию жизни помечен `transfer_hypothesis`; это не найденный экспериментальный эффект и не новая verified-комбинация.
