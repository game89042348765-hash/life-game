# До внедрения этапов блоков и новой Стратегии

Прежние WORK/CONTEXT сохранены дословно. Пользователь принял демо карты этапов и поручил заменить встроенную Стратегию, добавить этапы с собственными смыслами/целями/заданиями и условиями доступа. Старая схема графа сохранена для JSON-совместимости; новые действующие правила описаны в актуальных документах.
