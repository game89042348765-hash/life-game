# Итоговая сверка личной версии

11 ноября 2026. Основа — исходный Claude HTML с SHA из SOURCE.json и его 56 решений. Сравнение с нашей версией: `../downloads/LifeGame-comparison-Claude-2026-11-11.md`. Это сверка реализации на выбранной основе; она не объявляет автоматически принятыми все различия `next/`.

| Область | Что работает в личной версии | Проверка / граница |
|---|---|---|
| Вход | Пустая личная жизнь, восемь направлений, отдельное демо, Lite, семь добровольных шагов | Пустой старт и раздельные хранилища пройдены; демо не меняет личную дату |
| Блоки | Базовые и собственные, иконка, полная/простая/своя структура, приоритет, интенсивность, архив | Создание через UI; удаление собственного блока сохраняет действия и денежные факты |
| Стратегия | История, факт, текущий и планируемые этапы, ориентир; в полной — неизвестное и LVMG | Сохранены редакторы и виды Claude; новый графический дизайн не добавлен |
| Этапы | Создать, править, вставить/переставить, назначить текущим, завершить, вернуть, архивировать/удалить | Закрытие через форму переносит незавершённое с сохранением ID; следующий этап становится текущим |
| Цели | Активна/достигнута/отказ, возврат, «если — то», связи действий | Ручные статусы, без штрафа и отдельной денежной награды |
| Задания | Разовые с датой/без, daily/weekly/дни, награда, цель, ключевое, Конструктор | Реальный UI до выполнения; независимые флаги и новый цикл расписания проверены |
| Привычки | Отдельный раздел, расписание, цель за всё время/период, уровни | Один факт в день; порог и зависимая отмена проверены |
| Квесты | Счётчик и чек-лист, награды за шаг/финал, связь с этапом/днём | Финал/отмена, повторяющиеся названия, запрет изменения начатого типа проверены |
| Календарь | Одиночные даты, время, напоминание, связь с блоком/этапом | Дата выполненного защищена; пропуск сохраняется в паузе |
| Конструктор | План по расписанию, ключевые, ручное добавление, убрать только сегодня, темп | Неделя с настоящими сменами календарной даты, без тестового переключателя |
| Режимы | Отдых/обычный/фигачу, фокус, творческая пауза, показать скрытое | Скрытое не образует пропуск; календарь и ручное добавление имеют принятые исключения |
| Невыполненные | Датированные записи, выполнить позже/перенести, выбор/фильтры/архив | Rollover до операции, отдых/пауза/удаление из дня проверены; прошлые факты не заменяются сегодняшними |
| Экономика | Монеты и XP, уровни, журнал, точная отмена | Повторное начисление/возврат запрещены; нехватка средств блокирует отмену |
| Бонусы | Каталог, назначения/резервы, экземпляры, использования, покупка/возврат | Снимки условий, одноразовое использование, возврат по уплаченному, использованный приз блокирует отмену |
| Решения | Текст/срок/привязка, ручной исход, добровольная Цена слова | Отрицательный баланс и точная компенсация проверены; автоматического штрафа нет |
| Входящие | Мысли, превращение в запись, недавнее, быстрое добавление/выполнение, поиск | Сохранён исходный интерфейс; недавнее не удаляет саму запись |
| Пересмотр | Итоги, ритуал, дневные/недельные/месячные сессии | Сохранение ответов трёх уровней пройдено; месячная форма меняет приоритет/интенсивность |
| Виджеты | Таймер, первый шаг, график, счастье, ритм, моя награда | Сохранён каталог/добавление в день; нет автоматических наград за таймер |
| Сохранения | Проверяемая запись, backup, импорт/экспорт файлом, восстановление | Ошибка основного/резервного setItem, плохой JSON, реальные две вкладки проверены |
| Установка | Manifest, иконки, offline service worker, обновление по кнопке | Настоящий SW: офлайн reload/выполнение/reload; обновление сохраняет прогресс и открытый черновик |
| Напоминания | Баннер и доступное системное уведомление в открытом приложении | Однократность и сохранение отметки проверены; закрытый браузер не проверяется как будильник |
| Внешние сервисы | Нет обязательных библиотек/CDN/шрифтов/платных API | Реальный ИИ/голос, видео, аккаунт и синхронизация не реализованы и не объявлены работающими |

Все шесть воспроизведённых дефектов исходного сравнения исправлены: ложный успех сохранения, перезапись другой вкладкой, замена повреждённой жизни пустой, повторное включение Конструктора, изменение назначенной награды вслед за магазином и исчезновение вчерашнего пропуска на границе суток. Дополнительно исправлены ошибки календарной даты, выключения звезды/Конструктора, одноразового использования и возврата, зависимых финалов, ID пунктов и фонового таймера.

Из нашей работы использованы инженерные решения и подход к проверкам; ограничения/экономика `next/`, прежний дизайн, корневые сохранения и виджеты автоматически не переносились. Новые правила и оставшиеся отличия перечислены в DECISIONS.md. Итог проверки — TESTING.md. Физические Safari/iPhone, экранная клавиатура и установка с пользовательского телефона ожидают ручной приёмки.
