# Готовые палитры оформления

7 ноября 2026. Пользователь попросил оживить значки/иллюстрации и добавить любимый цвет в настройки; явно выбрал только готовые палитры.

## Выбор

Настройки → Оформление → текущий цвет. 6 семейств, 3 оттенка в каждом. Нет произвольного picker/HEX-поля. Изменение видно в предпросмотре; Применить сохраняет, Отмена/Escape возвращают последнюю сохранённую тему. Стандартная тема — золотая, основной оттенок #ffd54a. Кнопка по умолчанию меняет только предпросмотр до применения.

## Роли и данные

- --accent-fill — выбранный цвет заливки; --on-accent — чёрный/белый по максимальному контрасту. --theme-accent/--accent — цвет значков/текста, осветлённый при необходимости до контраста ≥4.5 к #333333. --accent-rgb — прозрачные подложки. --positive/совместимый --green используют акцент. Во всех 18 вариантах контраст текста кнопки ≥4.5.
- Графитовые фоны/геометрия сохранены. Акцентируют кнопки, значки разделов, прогресс и выбор; стрелки/меню/неактивные служебные элементы нейтральные. Категории графика и опасные/ошибочные состояния не перекрашиваются темой. AI-иллюстрация имеет естественные цвета с нейтральным затемнением.
- Отдельный browser key lifegame-appearance-v1: {version:1,palette,shade}; проверяются только известные id и версия. Цвет не входит в игровой JSON, не меняет валюты/награды/планы. Некорректная настройка даёт стандартную тему без очистки данных. При отказе записи диалог сообщает об ошибке и позволяет отмену.
- Storage event обновляет другие вкладки без render игрового экрана; введённые поля остаются. При открытом предпросмотре внешний выбор запоминается, но не перебивает черновик. Cancel берёт последний сохранённый, Apply сохраняет явный местный выбор. CSS-переходы цвета кратко подавляются при применении, чтобы не было промежуточного плохого контраста.

## Проверки

18 живых вариантов, реальные цвета кнопок, Apply/reload, Cancel/Escape, quota failure, malformed preference, вкладки с открытым черновиком, неизменный игровой JSON. Визуальные проверки 6 палитр/значков/изображений и трёх тёмных тем с белым текстом. Прежние формы, 14 виджетов, таймер/запись минут/выполнение/награда/итог дня. Изолированный Chromium, вымышленные данные, внешние запросы блокированы. Результаты/копия/публикация — в LifeGame_CURRENT_WORK.md. Реальные Safari/iOS и ручная приёмка отдельно.
