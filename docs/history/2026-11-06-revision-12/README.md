# История LifeGame — документы до прямой работы с агентом

Сохранено 6 ноября 2026 года перед переходом к редакции 13. Четыре исходных файла скопированы побайтово без редактирования. Размеры и SHA-256 находятся в [manifest.json](manifest.json).

- [Паспорт редакции 12](LifeGame_PROJECT_CONTEXT.md): подробная архитектура прежнего среза, история этапов и приёмок.
- [WORK редакции 12](LifeGame_CURRENT_WORK.md): прежние статусы и хронология.
- [Передача контекста редакции 12](LifeGame_CHAT_HANDOFF_2026-11-06.md).
- [Прежний .clinerules](.clinerules.txt): сохранён с расширением .txt, чтобы отличать историческую копию от действующих правил.

Это архив свидетельств, а не действующая инструкция агенту. Старые требования передавать промпт Cline, запрашивать файл с ПК при доступном актуальном checkout и запрещать все запуски заменены согласованным процессом в корневом AGENTS.md. Исторические разрешения на публикацию не действуют на новые задачи. Отменённые функции и старые версии не восстанавливать по этим текстам.

Копии HTML, ZIP, отчёты и файлы с ПК, упомянутые внутри старых документов, этим архивом не создавались; их наличие здесь не подтверждается. Личных данных браузера и экспорта прогресса архив не содержит. Прикладные файлы во время обновления документации не менялись.
