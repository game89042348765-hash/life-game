## Как будем сравнивать новый чат

Каждое положение нового чата получит ссылку на сообщение/фрагмент и тип: пожелание, вариант, окончательное решение, отменённое решение или вопрос. Затем сопоставим с текущим поведением и назначим статус: **сохранить / изменить / новое / забыто / сознательно исключить / противоречие / решить позже**.

Отсутствие упоминания не означает согласие удалить функцию. Старое наличие не означает обязательство её сохранить. Последнее явное решение пользователя важнее раннего варианта. Для противоречий сначала формулируем последствия и вопрос, не выбираем ответ молча.

После сравнения создадим отдельную финальную спецификацию: словарь сущностей, сценарии, связи, состояния, экономика, расписания, границы первой версии, критерии приёмки и решения о переносе данных. До этого новая архитектура и код основного приложения не меняются.
