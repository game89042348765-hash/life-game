## Что принято в этом обсуждении

- Единая навигация: обычные разделы и блоки **«Главная / Конструктор / Назад» + ⚙ справа**; рабочие ⚙ блоков сохранены, декоративные «скоро» неактивны. «Назад» использует существующую ограниченную историю. Нижняя вкладка **«Главная»**. На Главной **нет верхней панели ссылок/⚙**. Пользователь прошёл **7/7** проверки навигации.
- Конструктор дня: **«Главная / Виджеты / Блоки / Квесты / Календарь» + отключённая ⚙**; подзаголовок **«Собери день который хочешь прожить»**. Пять секций **Виджеты, Календарь, Задания, Квесты, Выполнено**, жёлтые разделители и независимые `+ / −`. Все непустые раскрыты по умолчанию. Пустые секции скрываются полностью; если пусто всё — стандартная `.empty` **«Пока здесь ничего нет. Добавь первое.»**. Старый видимый «План на сегодня» скрыт, правило +100 не менялось. Пользователь сообщил, что теперь всё работает.

## Открыто, не делать без согласования

1. **Виджет плана дня** со страйком и стратегиями «В ударе / В потоке / Устал / Отдыхаю». Это только идея, ни правила изменения числа дел, ни начисления, ни хранение не утверждены. **Напомнить о ней после окончания работы над Конструктором дня.**
2. **«Куда дальше»** — будущий контекстный рекомендуемый переход (текущий «Назад» уже работает).
3. **AUD-10-02** — архивные объекты в read-only контексте LifeGame AI: исключать или маркировать, ещё не решено.
4. Независимые регрессионные проверки Codex актуального HTML, только по прямому разрешению и на изолированной копии с вымышленными данными.

## Ограничения разработки

Обсуждение не равно разрешению на реализацию. Для утверждённого HTML-патча — один самодостаточный точечный `.md` Cline с уникальными якорями, предварительными проверками, одной новой резервной копией и побайтовым контролем до записи. Не менять `lifegame-prototype-v1`, экспорт JSON версии 1, экономику, архив, AI/ключи, пользовательские данные, зависимости или публикацию. Без отдельного разрешения не запускать приложение, браузер и тесты. Рабочая приёмка за пользователем.
