# LifeGame Personal

Рабочая личная версия на основе интерфейса и модели Claude. Адрес: **https://game89042348765-hash.github.io/life-game/personal/**.

## Как начать

1. Откройте «Начать свою жизнь в LifeGame». Здесь восемь базовых направлений, без примеров и готовых заданий. «Посмотреть пример» открывает отдельное пространство с вымышленной жизнью.
2. В «Карте» выберите направление или добавьте свой блок. Создайте этап, опишите смысл, добавьте цель и нужные действия. Полная/упрощённая стратегия и отдельные галочки определяют видимые разделы.
3. В задании настройте расписание, награду, связь с целью, Конструктор и ключевой признак. Привычки, квесты и календарь доступны в самостоятельных разделах и могут ссылаться на этап.
4. Во вкладке «День» выберите темп, выполните дела или добавьте что-то только на сегодня. Скрытые отдыхом, фокусом или творческой паузой действия не становятся пропусками. Календарные обязательства сохраняют свою дату.
5. Закройте день ритуалом, при желании ответьте на вопросы дня/недели/месяца. Этап завершает человек; приложение предложит судьбу незавершённых дел.

На главной доступны Lite, пример и семидневное сопровождение через «Обучение»/«Настройки». Это добровольные способы входа в одну систему.

## Установка и данные

На iPhone откройте ссылку в Safari → «Поделиться» → «На экран “Домой”». На Android используйте установку из меню браузера. Сначала требуется открытие с интернетом; затем приложение и сохранение работают без сети. Обновление предлагается отдельно и не перезагружает открытый редактор.

Все данные остаются **в браузере этого устройства**. Серверной синхронизации и аккаунта нет. В «Разделы → Настройки и сохранение» доступны экспорт JSON файлом, импорт и сброс с вводом «СБРОС». Экспорт включает историю, связи, настройки, награды и долги. Перенос между устройствами выполняется этим файлом. Очистка данных браузера удаляет локальный прогресс; предыдущая исправная копия хранится там же и не заменяет внешний экспорт.

Совместимы экспорты Claude `LifeGame / demo-2` и новые `LifeGame Personal / personal-1`. JSON прежнего корневого приложения и `next/` имеют другую модель и не импортируются автоматически. Чужие пространства и ключи не читаются/не очищаются.

При ошибке записи выполнение не подтверждается и награда не меняется. При повреждённом файле приложение сохраняет исходные байты и показывает восстановление. Есть скачивание исходных данных и предыдущей исправной копии. После конфликта вкладок черновик остаётся на экране: скопируйте нужное и нажмите «Обновить данные», затем откройте запись заново. Автоматического объединения черновиков нет.

Напоминания проверяются **в открытом работающем приложении**. Системное уведомление требует поддержки браузера и отдельного разрешения; закрытый браузер не является надёжным будильником. Настоящий ИИ/голос и обучающие видео пока обозначены как будущие возможности.

## Устройство проекта

- `index.html`, `style.css`, `app.js` — компактный интерфейс и исходная бизнес-модель Claude с исправлениями.
- `persistence.js` — проверка формата, очередь, Web Locks, контроль сохранённого снимка и предыдущая исправная копия.
- `pwa.js`, `sw.js`, манифест/иконки — установка, локальная оболочка, управляемое обновление.
- `SOURCE.json` — происхождение и проверенный исходный HTML; `DECISIONS.md`, `AUDIT.md`, `TESTING.md` — изменения правил, сверка, проверки.

Никакой сборки и внешних зависимостей для запуска. Из корня репозитория: `python -m http.server 8041 --bind 127.0.0.1`, затем `/personal/`. Для автономности/установки нужен localhost или HTTPS, не открытие HTML через `file://`.

При выпуске следующего изменения ресурсов увеличивайте версию `CACHE` в `sw.js`: оболочка обновляется целиком и не должна оставаться под прежним именем кэша.

## Область этой версии

Корневые `index.html`/`assets/` и наша предыдущая `next/` сохранены без изменений. Их правила и исправления автоматически сюда не переносятся. Это отдельное приложение для личного использования с настоящим локальным сохранением. Физическая приёмка на вашем iPhone остаётся следующим шагом.
