# LifeGame — обновлённый дизайн

Рабочая версия основана на предоставленном index.html размером 406 376 байт с принятой «Игрой в счастье» v3. Концепция из concept.rar адаптирована к актуальному приложению; демонстрационный preview.js не используется.

## Что изменено

- Пейзажная главная, более заметный Конструктор дня и компактные входы в инструменты.
- Общие цвета, карточки, формы, нижняя навигация и встроенные SVG-иконки.
- Оформление календаря, целей, квестов, магазина, ИИ и всех доступных виджетов.
- Читаемые подписи, заметный фокус клавиатуры, поддержка уменьшения анимации и компоновка для узких экранов.
- Новых внешних библиотек, шрифтов, аналитики и API не добавлено.

## Файлы

- index.html — приложение со встроенными CSS и JavaScript.
- lifegame_happiness_200_messages.json — исходная база 200 реплик.
- assets/images/journey.png и assets/images/quiet-focus.png — иллюстрации из предоставленной концепции.
- lifegame-design.zip — готовый комплект для скачивания. Внутри него backups/index-2026-11-04-16-33-40.html — точная копия исходного HTML до оформления, побайтовое совпадение проверено. Локальная копия также сохранена в облачной среде.

Сохраняйте структуру папок: иллюстрации загружаются по относительным путям. Установка зависимостей и сборка не нужны. Приложение не публиковалось автоматически.

## Запуск

Откройте index.html в браузере. Для автоматической загрузки базы реплик удобнее HTTP-сервер. Например, из папки приложения при установленном Python:

```sh
python3 -m http.server 8000
```

В Windows команда может называться `python`. При открытии через file:// базу можно выбрать вручную в настройках «Игры в счастье», как в исходной версии.

## Прогресс

Ключ `lifegame-prototype-v1`, схема состояния и JSON-экспорт версии 1 сохранены. Логика наград, транзакций, миграций, таймера и API-запросов не менялась. Прогресс привязан к браузеру и адресу приложения. Для переноса между адресами используйте штатную JSON-копию из настроек. Архив не содержит личного прогресса или API-ключей.
