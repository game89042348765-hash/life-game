## Что передаётся

- Копия `personal-lab/` с отдельными ключами данных, Web Lock, PWA-кэшем и метками Lab. Исходник и хеши — BASELINE.json.
- Исполняемый браузерный стенд, три готовых промпта, конфигурации 3×7 и 16×30 дат.
- Фактически выполненный пилот: 3 разных AI-контекста, 16 сессий, 5 дат без входа, 120 действий. Все 16 снимков состояния валидны. Это не завершённый месячный опыт.
- Компактные доказательства в Git; полные тяжёлые трассы/профили остались в исходной машине и явно перечислены как не включённые. Не опираться на их доступность в другом аккаунте.
- Один независимо воспроизведённый дефект классификации подхода привычки и четыре UX-затруднения. Двойная выплата и потеря сохранённых данных не подтверждены. Продуктовые исправления не выполнялись.
- Исправление обнаруженной проблемы видимости текста в самом стенде, отдельные технические проверки. Исходные свидетельства пилота сохранены без перезаписи.

Если в основной рабочей копии есть незавершённая работа, сначала проверь git status. Для чтения файлов необязательно переключать её ветку:

```sh
git fetch origin lab/synthetic-users
git show origin/lab/synthetic-users:LABORATORY_HANDOFF.md
git show origin/lab/synthetic-users:personal-lab/research/LAB-002-digital-month/RESULTS.md
```

Не сбрасывать изменения основного проекта ради чтения. Перед любым выбранным переносом сравнить исходный срез, текущую основную версию и лабораторию; исключить лабораторные имена хранилища/кэша. Перенос в Personal — отдельное поручение.
